# Workflow diagrams (PNG export)

ไฟล์ `.mmd` คือแหล่ง Mermaid — เรนเดอร์ PNG ด้วย:

```bash
npx -y @mermaid-js/mermaid-cli@11.4.0 -i docs/diagrams/01-shell-menu.mmd -o docs/diagrams/01-shell-menu.png -b white -s 2
```
